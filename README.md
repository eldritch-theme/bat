### Installation

1. Download your preferred variant from [themes](themes) and copy into the `~/.config/bat/themes` directory
2. Execute the following command to rebuild `bat`'s cache:
   ```sh
   bat cache --build
   ```
3. Edit your configuration file (`~/.config/bat/config`) and add your preferred variant:
   ```
   --theme="Eldritch Dusk"

   --theme="Eldritch Cthulhu"

   --theme="Eldritch Abyss"
   ```
